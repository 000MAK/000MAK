## About

My public repositories focus on applied Python development, data processing, machine-learning experiments, quantitative analysis, and small automation tools.

I prefer projects that are inspectable and understandable: documented inputs, explicit assumptions, practical evaluation, safe file handling, and clear notes about limitations. Research prototypes are identified as such rather than presented as validated production systems.
