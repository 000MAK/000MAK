## Profile

I work at the intersection of data management, statistics, risk analysis, and applied software development. My academic background in Statistics and ongoing doctoral studies in Management Information Systems inform a structured approach to data quality, analytical methods, and decision support.

My public GitHub work includes research prototypes, reproducible learning examples, and small Python command-line utilities. I aim to make assumptions, data requirements, limitations, and setup steps explicit so that each project can be reviewed responsibly.
